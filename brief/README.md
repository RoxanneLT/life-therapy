# Brief — Life-Therapy

> **The index, and nothing else.** Arguments live in the file that owns them and get one line here.
> Conforms to `dev-standards/standards/BRIEF-STANDARD.md` v1.1.

**What this project is, in three sentences.** Life-Therapy is an online counselling and
life-coaching practice platform: Next.js on the App Router, Prisma over PostgreSQL, Supabase Auth,
Paystack, deployed on Vercel. Admin manages clients, bookings, billing, courses, digital products
and email; clients get a portal for bookings, session history, course content and invoices. Two
domains — `life-therapy.co.za` (SA, ZAR) and `life-therapy.online` (international) — share one
deployment, with the region decided per request from the hostname.

**This brief is TRACKED.** In git, in this repo, like every other file here. The sibling project
`pleks` runs its `brief/` as a symlink into OneDrive, gitignored and untracked, and that shape is
**disqualified here** rather than merely unchosen: §6 of `CLAUDE.md` records OneDrive destroying
this repository on 2026-08-17 — 118 git objects unreadable — and §1 makes living outside OneDrive
the project's invariant. An untracked brief would also mean a fresh clone has nothing for the gate
to check, which is this repo's "a test file nobody runs is not a failing test, it is an absent one".
